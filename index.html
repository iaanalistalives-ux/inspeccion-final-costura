1. Datos de la inspección
Se llena una sola vez y queda fijo. Al guardar un estilo, estos datos NO se borran: solo se limpia el estilo para registrar el siguiente. Si cambias de línea, cambia el selector y sigue registrando: cada registro guarda la línea que estaba activa.
2. Estilo y carga
Carga = cantidad de prendas revisadas en ese estilo. Si son varias cargas, escríbelas separadas por espacio o con “+” (ejemplo: 20 30 o 10+10) y el sistema las suma solo.
Si el estilo es nuevo, escríbelo igual: queda guardado para la próxima vez.
Carga total: 0 prendas
3. Defectos encontrados
Elige el defecto, pon cuántas prendas salieron con él y agrégalo. Se cuenta una prenda con un solo defecto. Las filas marcadas “no resta” (re-inspección y rechazo de auditoría) se registran pero no descuentan de las primeras.
    Todavía no se agregó ningún defecto. Si la carga salió limpia, deja esto vacío y guarda: todas las prendas van como primeras.

    Cargando registros…
    ¿Cómo se calcula esto?

    Primeras = Carga − Defectos que restan. Restan todas las filas de compostura, manchas, zurcido, hilos, segundas y primeras especiales. No restan re-inspección (2da y 3era vuelta) ni rechazo de auditoría: se registran para poder analizarlos, pero no descuentan prendas, porque no son una prenda distinta que se pierde sino algo que le pasó a la carga.

    Regla de conteo: cada prenda se marca en un solo defecto, el principal. Si una prenda con mancha y puntada saltada se marca en las dos filas, esa prenda se descuenta dos veces y las primeras quedan por debajo de lo real. Por eso el sistema avisa cuando los defectos superan la carga.

    Defecto nuevo: el botón “Defecto nuevo” agrega la falla a la lista para siempre, en el grupo que elijas, y desde ese momento aparece para todos. Se guarda en MAYÚSCULAS y no se puede repetir. Un defecto nuevo siempre resta de las primeras.

    Eliminar: el registro desaparece del formulario y del tablero, pero la fila queda tachada en el Google Sheet con la marca ANULADO. Así se puede saber después qué se borró y cuándo.

    Términos: Carga = grupo de prendas que se revisa de una vez. Primeras = prendas conformes, listas para pasar. Segundas = prendas con falla que no se recuperan como primera. Compostura = falla de costura que se arregla cosiendo de nuevo. Zurcido = falla de tela o puntada que se repara con aguja. Rechazo de auditoría = la carga fue rechazada en la auditoría posterior.
